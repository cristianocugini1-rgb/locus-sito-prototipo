# Locus: prototipo del sito

Prototipo del sito immersivo di Locus, associazione di giovani a Parma (@locus_parma).

Si apre, si clicca "entra" con il suono acceso e si scorre: la bolla, i tre anelli, il nastro di foto,
il Battistero di grani, la chiusura. Meglio dal computer.

Per lavorarci in locale: `npm install`, poi `npm run dev`.
